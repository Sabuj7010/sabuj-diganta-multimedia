# সবুজ দিগন্ত মাল্টিমিডিয়া — Leadership Website

এই প্যাকেজটি GitHub Pages-এ সরাসরি ব্যবহারযোগ্য একটি responsive static website।

## ফাইল
- `index.html` — মূল ওয়েবসাইট
- `style.css` — সম্পূর্ণ ডিজাইন ও responsive layout
- `script.js` — mobile menu, profile modal ও dynamic year
- `assets/chairman.png` — Chairman portrait
- `assets/logo.png` — brand logo

## GitHub Pages
এই ফাইলগুলো repository-এর root-এ রেখে **Settings → Pages → Deploy from branch → main / root** নির্বাচন করুন।
