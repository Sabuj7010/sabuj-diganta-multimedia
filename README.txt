# সবুজ দিগন্ত মাল্টিমিডিয়া — Website
ফাইল: index.html, style.css, script.js

ব্যবহার:
1. তিনটি ফাইল একই ফোল্ডারে রাখুন।
2. index.html ব্রাউজারে খুললেই ওয়েবসাইট দেখা যাবে।
3. GitHub Pages-এ প্রকাশ করতে চাইলে এই তিনটি ফাইল একটি GitHub repository-তে আপলোড করে Settings → Pages থেকে Deploy from branch নির্বাচন করুন।

নোট: যোগাযোগের ইমেইল/ফোন এবং ভবিষ্যতে নিয়োগের পদগুলোর নাম প্রয়োজন অনুযায়ী বদলাতে পারবেন।
